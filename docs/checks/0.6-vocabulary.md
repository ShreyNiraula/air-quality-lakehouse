# Check 0.6: Vocabulary

Read on 5 October 2026. Nothing differs from the vocabulary table in `plan.md`, so the table is not changed.

## Standard names (CF)

Source: the CF standard-name table, version 95, last modified 16 September 2026, at <https://cfconventions.org/Data/cf-standard-names/current/src/cf-standard-name-table.xml>. The script reads it; its output is in `generated/0.6-vocabulary.txt`.

| Parameter | CF standard name | In the table | CF's own unit |
|---|---|---|---|
| `pm25` | `mass_concentration_of_pm2p5_ambient_aerosol_particles_in_air` | yes | `kg m-3` |
| `temperature` | `air_temperature` | yes | `K` |
| `relative_humidity` | `relative_humidity` | yes | `1` |

CF's unit for relative humidity is `1`, a fraction, which `plan.md` does not state. The platform stores percent, so a stored 50 is CF's 0.5. This matches the plan's rule that CF supplies the name only.

## Unit spellings (UCUM)

Source: the UCUM tables, version 2.2 of 17 June 2024, published by the UCUM organization at <https://raw.githubusercontent.com/ucum-org/ucum/main/ucum-essence.xml>. The specification they belong to is at <https://ucum.org/ucum>. The script reads the tables.

- `ug/m3` is valid: the prefix `u` (micro) on `g` (gram), per `m` (meter) to the power 3.
- `Cel` is the code for degree Celsius, and `%` for percent.
- A Greek mu and a superscript three are not UCUM, so `μg/m3` and `ug/m³` are not valid codes. The files' `µg/m³` is matched by the unit rule; the stored spelling stays `ug/m3`.

## WHO guideline value

Read by eye, not by the script. Source: *WHO global air quality guidelines: particulate matter (PM2.5 and PM10), ozone, nitrogen dioxide, sulfur dioxide and carbon monoxide* (2021), <https://iris.who.int/handle/10665/345329>, file `9789240034228-eng.pdf` (7,321,751 bytes, SHA-256 `32f3bf1470e20803decb63ab1ee5babf289b4182bc8af94d62b7a5b998642353`).

Table 0.1, "Recommended AQG levels and interim targets", on page xvii (page 19 of the PDF), gives for PM2.5 with a 24-hour averaging time the interim targets 75, 50, 37.5 and 25 and the **AQG level 15 µg/m³**. Its footnote reads "99th percentile (i.e. 3–4 exceedance days per year)". Both agree with `plan.md`.

The download link on the WHO page needs a browser. The same file is served without one at <https://iris.who.int/server/api/core/bitstreams/551b515e-2a32-4e1a-a58c-cdaecd395b19/content>.
